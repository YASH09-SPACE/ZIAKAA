# 🍴 Zaikaa – Food Delivery App

Zaikaa is a mobile-based food delivery application designed to provide a seamless ordering experience for customers, restaurant owners, and administrators.  
Built with a scalable architecture and real-time order tracking, Zaikaa aims to simplify food ordering and restaurant management, especially in Tier 2 and Tier 3 cities.

---

## 🚀 Features

### 👨‍🍳 For Customers
- Browse restaurants and menus by category or cuisine  
- Add items to the cart and place secure orders  
- Real-time order tracking and delivery updates  
- View order history and reorder with one click  
- Manage profile and delivery addresses  

### 🏪 For Restaurant Owners
- Manage menu items, prices, and availability  
- View and process incoming orders  
- Update order status in real-time  
- Analyze sales and customer feedback  

### 🧑‍💻 For Admins
- Monitor platform performance and reports  
- Manage users, restaurants, and orders  
- Handle complaints and feedback  

---

## 📱 App Scope

- Android app supporting the **latest Android version**  
- Firebase integration for Authentication, Firestore Database, and Cloud Messaging  
- Multi-language support (English, Hindi, Gujarati)  
- Modular architecture for scalability and maintenance  

---

## ⚙️ Functional Requirements

- **User Authentication** (Signup, Login, Password Reset)  
- **Menu Browsing** with search and filters  
- **Cart & Checkout** with auto bill calculation  
- **Order Tracking** with real-time updates  
- **Order History & Reorder** functionality  
- **Profile Management** with personal preferences  

---

## 🧩 Non-Functional Requirements

- **Performance:** Fast response (<2 seconds)  
- **Security:** Encrypted data, OAuth 2.0, and SSL  
- **Usability:** Intuitive and mobile-friendly interface  
- **Reliability:** 99% uptime with Firebase backend  
- **Maintainability:** Modular, scalable design  

---

## ⚠️ Limitations

- Currently available for **Android only** (supports latest version)  
- Internet connection required  
- Firebase dependency  
- Limited free-tier scaling in Firebase  

---

## 💡 Future Enhancements
